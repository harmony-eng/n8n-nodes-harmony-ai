# n8n-nodes-harmony-ai

n8n community nodes for [Harmony AI](https://harmony.ai) voice agents.

- **Harmony AI Trigger** starts a flow when a call starts, ends, or has a recording ready.
- **Harmony AI** adds contacts to a voice agent's workflow, creates and updates contacts, and looks up contacts, their calls, and call transcripts. It can also run as an AI Agent tool.

## Install

In n8n, go to **Settings > Community Nodes > Install** and enter `n8n-nodes-harmony-ai`.

## Credentials

Create an API key in Harmony under **Settings > Developers**, then add a **Harmony AI API** credential in n8n with that key. The credential finds your Harmony region, US or EU, from the key.

A Viewer's key can run the Get operations only. Adding contacts, changing contacts, and triggers need a key whose owner can make those changes.

## Documentation

The [Harmony n8n guide](https://docs.harmony.ai/guides/deploy/integrations/n8n/overview/) covers setup, every operation, and example flows.

## Development

```bash
npm ci
npm run typecheck
npm test
npm run build
```

`shared/harmony-public-api.gen.ts` holds types generated by `@hey-api/openapi-ts` from Harmony's public OpenAPI spec. Replace it when the public API changes.
